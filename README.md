# Behind the Bots mockups

Shareable clickable mockups, served by GitHub Pages at https://jwheezy69.github.io/btb-mockups/

- `ac-maintenance-quote/` AC maintenance quote form (customer photo flow and office view). Source and
  build script live in the Behind the Bots Drive, `sales\hvac-quote-form\`; copy the built HTML and
  `screenshots\` here after a rebuild.
- `missed-call-text/` Missed call text back for B&T Pressure Washing (caller's phone, owner's phone, CRM
  Calls pages). Source and build script in the Behind the Bots Drive, `sales\missed-call-text\`
  (`sourceuild.py`); copy the built HTML and `screenshots\` here after a rebuild.

Sample companies, people and prices only. Photos: Unsplash (free license); missed-call-text photos from Wikimedia Commons (CC0, CC BY-SA 4.0, credited on the page).
